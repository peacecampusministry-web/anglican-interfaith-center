# Anglican Interfaith Center

Open index.html to preview the site. The homepage slideshow rotates through 10 photos. The Photos page has 14 photos. The Resources page has five edited articles across four categories.

## Upload to GitHub

Extract the ZIP. In the Anglican Interfaith Center repository, choose Add file > Upload files. Drag all extracted HTML, CSS and JavaScript files and the photos folder into the upload area. Verify that index.html and resources.html are at the top level, with the JPEGs under photos/. Commit to main. The existing GitHub Pages settings publish from main automatically.
