# Anglican Interfaith Center

A static website for GitHub Pages. Open `index.html` in your browser to preview it.

## Upload and publish

1. Extract this ZIP. Open [the repository](https://github.com/peacecampusministry-web/anglican-interfaith-center) and select **Add file → Upload files**.
2. Upload `index.html` and `styles.css` from inside the extracted folder so they appear at the top level of the repository. Commit to `main`. You can keep your existing README.
3. Open [Settings → Pages](https://github.com/peacecampusministry-web/anglican-interfaith-center/settings/pages). Set **Source** to **GitHub Actions**.
4. Choose **Static HTML → Configure** and commit GitHub's suggested workflow. The ZIP also includes `.github/workflows/static.yml` if you prefer to add the workflow manually. Use one workflow.
5. When the deployment succeeds in the **Actions** tab, visit [Anglican Interfaith Center](https://peacecampusministry-web.github.io/anglican-interfaith-center/).

## Edit the site

Update the welcome text and About section in `index.html` with your approved wording. The Participate section is ready for confirmed dates and a public contact address. Change colors and type in `styles.css`. Commits to `main` trigger deployment after the workflow is configured.


## Add the gallery photos

Put the 14 original JPEGs listed in photo-filenames.txt into a folder named photos beside index.html. Keep their original filenames. Open gallery.html to check that the photos appear. Upload gallery.html and the photos folder along with index.html and styles.css. The photo paths in GitHub should start with photos/.
